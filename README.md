# Personal Finance and Expense Tracker

## Project Overview
A multi-page web application built with PHP, MySQL, HTML5, and CSS3 designed to help users track personal budgets, log expenses, and manage spending categories securely.

## Features
- **User Authentication**: Secure registration, login, and session-based access control with hashed passwords.
- **CRUD Operations**: Log in to add, view, and delete daily personal expense records.
- **Responsive Layout**: Clean multi-page UI styled with custom CSS.

## Technologies Used
- PHP (MySQLi)
- MySQL Database (phpMyAdmin / XAMPP)
- HTML5 & CSS3
- JavaScript (Client-side interactivity)

## Database Setup Instructions

To set up and run the database for this project locally using XAMPP and phpMyAdmin, follow these steps:

1. **Start XAMPP**: Open the XAMPP Control Panel and start both **Apache** and **MySQL**.
2. **Open phpMyAdmin**: Open your web browser and go to `http://localhost/phpmyadmin`.
3. **Create a Database**: Create a new database named `finance_tracker` (or the name matching your database connection file).
4. **Import the SQL File**: 
   - Select your newly created database.
   - Click on the **Import** tab at the top.
   - Click **Choose File** and select your project's `database.sql` file.
   - Click **Go** at the bottom to execute and import the tables.
